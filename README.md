Palma Bay: Neon Tide is an original open-world crime game set in a sun-soaked bay city, where broke mechanic Rafi takes five story jobs for fixer Lulu Ferrer — stealing cars, running packages, dodging the Policia and chasing cash across town.
Explore the city on foot or in any car you can steal, with live traffic, pedestrians, a five-star wanted system, mouse-aimed combat, a HUD with minimap, synthesized sound, and progress that saves in your browser.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
